# CAB Simulator

A tongue-in-cheek browser game about chairing an IT Change Advisory Board,
loosely based on ITIL 4 change enablement.

## How to play

Open `index.html` in any browser. No install or build step needed.

For each change request (RFC), choose **Approve**, **Reject**, or
**Send Back for More Info**. Keep all four meters (Stability, Leadership
Happiness, Audit Readiness, Your Sanity) above zero.

## Files

| File         | What it's for                                              |
|--------------|------------------------------------------------------------|
| `index.html` | Page structure                                             |
| `style.css`  | Look and feel                                              |
| `data.js`    | **Scenario content** - characters and RFCs. Edit this one! |
| `game.js`    | Game rules and logic                                       |
